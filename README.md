# Culture du Québec

Application Android de normalisation, standardisation, recherche et valorisation des données culturelles du Québec.

Projet indépendant destiné à regrouper les fonctions de préparation aux normes sectorielles reconnues, la traçabilité, les indicateurs de reddition de comptes, les données culturelles publiques, la carte interactive et la vitrine des 11 nations autochtones du Québec.
